# ⚡ Análisis Exploratorio de Datos sobre Producción Eléctrica

## 📖 Descripción

Este proyecto explora la producción eléctrica de diferentes países a lo largo del tiempo mediante técnicas de Análisis Exploratorio de Datos (EDA).

El objetivo principal es estudiar la evolución de las energías renovables y analizar si existe una relación entre la adopción de fuentes limpias y factores económicos como el PIB nacional.

---

## 🎯 Preguntas de investigación

- ¿Ha aumentado el uso de energías renovables con el paso de los años?
- ¿Los países con mayor PIB producen más energía renovable?
- ¿La transición energética depende exclusivamente de la capacidad económica?
- ¿Existen países con economías modestas que destaquen en el uso de energías renovables?

---

## 📊 Dataset

El conjunto de datos incluye información sobre:

- Producción eléctrica por país.
- Tipo de fuente energética.
- Participación de cada fuente en la producción total.
- Producción acumulada anual.
- Datos temporales (años y meses).

---

## 🛠️ Tecnologías utilizadas

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 🔎 Principales análisis realizados

- Limpieza y transformación de datos.
- Clasificación de fuentes energéticas.
- Comparación entre energías renovables y no renovables.
- Análisis de crecimiento de energías renovables.
- Relación entre producción renovable y PIB.
- Comparaciones por país y continente.
- Visualizaciones orientadas a la toma de decisiones.

---

## 📌 Conclusiones

Los resultados sugieren que la adopción de energías renovables no depende únicamente de la riqueza de un país. Diversas economías de tamaño medio y pequeño muestran una fuerte presencia de fuentes renovables, lo que apunta a que factores políticos y estratégicos pueden ser tan importantes como la capacidad económica en la transición energética.
